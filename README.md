# resumo-do-lab
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO

Durante o Lab, aprendi utilizando azure desde como a computação em nuvem funciona, até os diferentes tipos de serviços, seus benefícios, como a escalabilidade, confiabilidade, a segurança, governança e também a gerenciabilidade.

Também aprendi sobre o conceito de "As a Service", os modelos de servidores locais, como isso pode funcionar em um negócio, a utilização de um ambiente On Premise e um ambiente Cloud, e como uma empresa pode lucrar utilizando esses modelos.
